# Dropzone

Drop anything in here. Photos, artwork, references, screenshots, whatever, in
whatever state. No need to name or sort it.

Then say "ingest the dropzone" and it gets identified, renamed to something
readable, filed into `Source files/` and listed in `Source files/INDEX.md`.
Web-ready versions get generated into `site/assets/` where the site needs them.

This folder is meant to be empty most of the time. If there is something in it,
it has not been filed yet.
